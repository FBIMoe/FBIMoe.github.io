# Small hand-drawn games

The public pages for the games (served by GitHub Pages at https://fbimoe.github.io/):

- `sketchgolf/` – Sketch Golf support page
- `sketchgolf/privacy.html` – Sketch Golf privacy policy

Plain HTML and CSS, no build step, no scripts and no third-party requests. The title font is Caveat (SIL Open Font
License 1.1, `assets/Caveat-OFL.txt`).
